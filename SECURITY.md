# Política de seguridad

## Versiones con soporte

| Versión | Soporte |
|---|---|
| 3.x | Sí |
| < 3.0 | No |

## Cómo reportar un problema de seguridad

No abras un issue público si el problema expone datos de estudiantes o profesores o credenciales.
Usa **Security > Report a vulnerability** en el repositorio de GitHub (reporte privado).
Si esa opción no está disponible, escribe al dueño del repositorio desde su perfil de GitHub.

## Qué no debe llegar nunca a este repositorio

- Respuestas reales del formulario, informes generados o listas de correos de personas.
- Credenciales: `.clasprc.json`, tokens o claves (están en `.gitignore`).

Las direcciones de correo de autoridades que existían en versiones anteriores siguen en el historial de Git; ver el [CHANGELOG](CHANGELOG.md).
